# Expense Tracker

This project is a simple expense-tracking webpage built as part of the Week 2 assignment. It includes a form for adding expenses, a full expense table, a budget tip video, and a collapsible help section.

## What is included

- `index.html`: The page structure, semantic layout, expense form, table, and multimedia elements.
- `style.css`: Styling for layout, colors, tables, hover states, focus effects, and advanced CSS selectors.

## Page sections

### Header
- Displays the page title and a small logo image at the top of the page.

### Add Expense Form
- Uses a proper `form` wrapper.
- Includes matching `id` attributes for each input.
- Replaces the old text input with a category dropdown using `select`.
- Includes a button labeled "Add Expense" with `type="button"`.

### Expense Table
- Contains a valid HTML table with `thead` and `tbody`.
- Shows five sample hardcoded expenses with column headers for Name, Amount, Category, and Date.
- Uses alternating row colors and hover highlighting.

### Multimedia Content
- Adds a small SVG logo image using the `img` tag.
- Embeds a YouTube budgeting video using an `iframe` with required attributes.

### Details and Summary
- Includes a collapsible "How to use this tracker" section using `details` and `summary`.

### CSS Styling
- Applies advanced selectors such as descendant selectors, direct child selectors, nth-child styling, focus states, and hover effects.

## Notes

This project is a static front-end build and does not yet include JavaScript functionality for adding expenses dynamically.
